# Generative AI Story Generator using LSTM

This project generates stories using an LSTM neural network trained from scratch without pretrained models.

## Technologies
- Python
- TensorFlow
- LSTM
- NLP

## Features
- Custom dataset training
- Story generation
- Deep learning from scratch
- Optional Streamlit UI

## Run Project

### Install Requirements
pip install -r requirements.txt

### Train Model
python train.py

### Generate Story
python generate.py
